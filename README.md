# Delight Cafe Menu Master

Responsive React/Vite menu-learning PWA for laptop and Android.

## Easiest online setup: GitHub Pages
1. Create a new **public** repository on GitHub, e.g. `delight-cafe-menu-master`. Do not initialize it with a README.
2. Extract this ZIP on your laptop. In the extracted folder, show hidden files so `.github` is visible.
3. Upload the project files and folders to the repository root, including `.github/workflows/deploy.yml`, `vite.config.js`, `package.json`, `index.html`, `src`, and `public`. Do not upload the ZIP as the only file.
4. In GitHub repository, open **Settings → Pages** and set **Build and deployment → Source: GitHub Actions**.
5. Open **Actions** and wait for “Deploy Delight Cafe Menu Master” to finish with a green check.
6. Open `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` on laptop or Android. Replace both parts with your actual GitHub username and repository name.
7. On Android Chrome, open the site, tap **⋮ → Add to Home screen** (or **Install app** if shown).

## Local testing (optional)
Install Node.js LTS, open this folder in VS Code, run `npm install`, then `npm run dev`.

## Important
The app is a web app/PWA, not a native APK. Menu details that are unclear in the provided images must be verified with the current printed menu or kitchen before treating them as confirmed. Data saved in browser storage stays on that device unless backed up/restored.
